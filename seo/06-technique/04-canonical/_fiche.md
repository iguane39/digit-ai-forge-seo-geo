# Technique / Canonical

> Volet **ETAT** -- statut **SD** (instrumente sans dependance externe)

## Question d'audit

Les canonicals sont-elles cohérentes et auto-référentes ?

## Source requise

crawl (HTML + en-têtes)

## Methode

relever la canonical de chaque page de l'échantillon ; détecter les canonicals croisées, vers non-200, ou incohérentes avec le sitemap et les hreflang

## Critere de verdict

0 canonical vers une page non-200 · 0 canonical croisée non intentionnelle · cohérence avec hreflang
